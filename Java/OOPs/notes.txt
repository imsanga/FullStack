Access specifiers:
public -> accessible from anywhere
private -> Accessible only within the same class
protected -> Protected members are accessible within the same package and in subclasses outside the package using inheritance.
default -> Accessible only within the same package
package -> it groups related classes and interfaces together.
----------
super keyword:
-> Used only in inheritance
-> It can access parent class data members (variables) except private.
-> It can access parent class methods except private.
-> It can access parent class constructors using super().
-> super() must be called inside a constructor & first line in constructor.
----------
ENCAPSULATION - hides data(Data hiding)
-> Encapsulation is the process of binding data members (variables) and methods together into a single unit (class).
-> It is achieved by making variables private and accessing them through public getters and setters.
-> Encapsulation focuses on protecting data from unauthorized access.
----------
Polymorphism - means many forms
Two types of polymorphism
--> Method Overloading (compile time polymophism) - same method name, different parameters
--> Method Overriding (run time polymophism)- defining the same method in subclass which is already present in parent class. During runtime, the JVM looks at the actual object(child). If the method is overridden in the child class, the child’s method is executed; otherwise, the parent’s method is executed.
----------
ABSTRACTION - shows only necessary functionality(Feature hiding)
-> Abstraction is the method of hiding unnecessary details and showing only essential features to the user.
----------
ENCAPSULATION vs ABSTRACTION

Abstraction → WHAT to do
- Wraps the class logic
- Exposes only required functionality
- Implemented using interfaces and abstract classes

Encapsulation → HOW it is protected
- Wraps data (variables) with methods
- Hides data using access modifiers

Example:
In an ATM, abstraction shows only banking services like withdraw and deposit, while encapsulation hides and protects sensitive data such as account balance.
----------
Inheritance - class inherits data members and methods of another class, except those declared as private.
